# Deploying ixegames

## Single Node process

1. Clone this repository onto a server with Node.js 22+.
2. Copy `.env.example` to `.env` and restrict it to the service user (`chmod 600 .env`).
3. Run `node scripts/password.mjs` in a private terminal and save its generated hash in `.env`.
4. Set SITE_URL to your actual public HTTPS origin, PORT to the upstream port, COOKIE_SECURE=true and NODE_ENV=production.
5. Set DATA_DIR to persistent storage writable only by the service user. Do not expose this directory through the web server.
6. Run `npm test`, then start the app under systemd, Supervisor or your process manager.
7. Proxy HTTPS traffic to Node. Only expose the proxy publicly.
8. Open `/admin` to publish your operator name, monitored contact email, announcement, and ad settings.

No `npm install` or compilation is needed for runtime. On a managed hosting platform, use its supported Node process/reverse-proxy configuration. Point the proxy at the Node port and preserve the external Host/Origin relationship. SITE_URL must exactly match the origin used to access Admin or write requests will be rejected.

## Environment

| Variable | Default | Purpose |
| --- | --- | --- |
| PORT | 3000 | Listening port |
| HOST | 0.0.0.0 | Bind address; use 127.0.0.1 behind a local proxy |
| SITE_URL | http://localhost:3000 | Canonical URLs, sitemap and admin origin validation |
| ADMIN_PASSWORD_HASH | empty | Salt:hash generated by the password helper; admin is locked if absent |
| COOKIE_SECURE | false | Must be true with production HTTPS |
| NODE_ENV | unset | Set production to enforce HTTPS, secure cookies and configured admin credentials |
| DATA_DIR | ./data | Persistent settings directory |
| CMP_SCRIPT_URL | empty | HTTPS script URL provided by your certified TCF CMP; no secrets |

If setting CMP_SCRIPT_URL, use a trusted HTTPS provider and configure that provider for your domain. The source origin is added to the script CSP. Some CMPs require additional script domains or initialization; follow ADSENSE.md before enabling Google ads.

## Example Nginx upstream location

Install certificates using your host's supported process. Within the appropriate HTTPS server block:

```nginx
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_read_timeout 30s;
    client_max_body_size 32k;
}
```

Redirect HTTP and alternate hostnames to the exact SITE_URL origin. Do not cache `/admin` or POST requests. Do not override the no-store authentication response header. Enable gzip/Brotli for text assets at the proxy if supported.

## Example systemd service

Adjust paths, Node binary and service user for the host. The working directory must contain `.env`.

```ini
[Unit]
Description=ixegames browser arcade
After=network.target

[Service]
Type=simple
User=ixegames
WorkingDirectory=/srv/ixegames
ExecStart=/usr/bin/node --env-file=/srv/ixegames/.env /srv/ixegames/server.js
Restart=on-failure
RestartSec=3
NoNewPrivileges=true
PrivateTmp=true
UMask=0077

[Install]
WantedBy=multi-user.target
```

Do not run the application as root. Keep administrator access behind additional host controls if appropriate. The application does not need root permissions.

## Backups and upgrades

Back up DATA_DIR, .env and any provider configuration securely. Before upgrading, run the tests and browser checks in QA.md, then restart the process. Restarting signs out administrators. Scores remain in player browsers. Rotate the admin password by generating a new hash and restarting, which also invalidates all sessions.

For multiple replicas, replace in-memory sessions and JSON settings with shared persistence before scaling. This release is designed for one process, not PM2 cluster mode or an ephemeral serverless filesystem.

## Domain and search launch

- Connect ixegames.com and configure HTTPS before changing SITE_URL to that origin.
- Confirm canonical tags and `/sitemap.xml` use the production origin.
- Verify Search Console ownership and submit the sitemap.
- Inspect a public game page with Google's URL inspection and structured-data tools.
- Do not enable production advertising until account, policy and consent setup is reviewed.
